# Mandi Center — онлайн-меню

QR-меню ресторана Mandi Center (арабская халяльная кухня, Астана).

**Сайт:** https://mandi-center-menu.vercel.app — дизайн «Сана».

## Варианты дизайна

Три варианта по итогам исследования ~30 меню (`research/menu_research.md`). У каждого свой репозиторий и свой сайт. Все проходят `check_prices.js` (126 позиций, 355 455 ₸).

| Вариант | Идея | Сайт | Репозиторий |
|---|---|---|---|
| «Бланк заказа» | Типографский листок: белая бумага, ультрамарин и оранжевый, манди — прайс-таблица «мясо × 1/2/5 персон» | https://mandi-menu-blank.vercel.app | https://github.com/Diyar30under30/mandi-menu-blank |
| «Карак-кафетерий» | Яркие цветовые поля по разделам, цены-наклейки, рукописные пометки, «человечки» 1/2/5 | https://mandi-menu-karak.vercel.app | https://github.com/Diyar30under30/mandi-menu-karak |
| «Сахан» | Стол с видом сверху на индиговой скатерти, блюда — круглые тарелки, поднос растёт 1 → 2 → 5 | https://mandi-menu-sahan.vercel.app | https://github.com/Diyar30under30/mandi-menu-sahan |

## Как обновить меню

Нужен Node.js.

1. Поправить данные в `menu_improved.json` (или стили в `design-v2/`).
2. Собрать страницу:
   ```
   node design-v2/build.js
   ```
3. Проверить цены:
   ```
   node check_prices.js menu_v2.html
   ```
   Должно быть «OK». Если цены меняли намеренно, сначала обновите эталон `menu_data.json`.
4. Скопировать в папку загрузки и выложить:
   ```
   cp menu_v2.html mandi-center-menu/index.html
   cd mandi-center-menu && vercel deploy --prod
   ```
   Если добавились новые фото, скопируйте их в `mandi-center-menu/images/`.

## Важно

- Корзина («Ваш поднос») хранится только в браузере гостя и никуда не отправляет заказ.
- Цены, состав и порции взяты со старого сайта без изменений. Открытые вопросы (граммовки, аллергены, цены порций на 2 персоны у BBQ и судака) — в `questions.md`.
